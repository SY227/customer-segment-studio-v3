# Customer Segment Studio V3

**Version:** 3.0.0
**Edition:** Evidence + Action

V3 promotes the complete Customer Segment Studio V2.1 Outreach Ready
application into a new independent GitHub and Vercel product line.

The product logic remains the Evidence + Action release:

- deterministic purchase-history RFM segmentation
- nine preserved customer-group identities
- original 3D Living Segment Map and character assets
- member-level segment drilldown
- assignment evidence
- analysis-basis and data-quality review
- CSV / Excel import mapping
- action-list exports
- optional AI-written soft guidance that cannot change hard metrics

V3 does not add churn prediction, renewal forecasting, CRM integrations,
customer-health scoring, authentication, billing, or database persistence.

The deployment workflow requires the complete local QA suite, TypeScript
validation, and production Next.js build to succeed before remote creation
and production deployment.
